## What Makes Something an "Agent"?

A chatbot produces one response and stops. An **agent** runs a loop: it reasons about a goal, optionally **calls a tool**, **observes** the result, and decides whether to continue — repeating until the task is done.

Frameworks like CrewAI, AutoGen, and LangGraph hide this loop behind nice abstractions. That's great for building, but it makes the core idea feel like magic. The fastest way to actually *understand* agents is to build the loop yourself, once, with nothing but the OpenAI SDK. That's the skill you'll walk away with — and it transfers directly to reading and debugging any framework.

```text
goal → [ model decides ] ──tool call?──yes──► run tool ──► feed result back ──┐
              ▲                                                                │
              └────────────────────────────────────────────────────────── observe
              │
              └──no (final answer)──► done
```

## Step 1: Define Tools

A tool is a function plus a JSON schema that tells the model how to call it. We'll give the agent two: exact arithmetic and a (fake) live currency rate — both things an LLM can't do reliably on its own.

```python
import json

def calculator(expression: str) -> str:
    """Evaluate a basic arithmetic expression like '240 * 0.15'."""
    allowed = set("0123456789+-*/(). ")
    if not set(expression) <= allowed:
        return "Error: only numbers and + - * / ( ) allowed."
    return str(eval(expression, {"__builtins__": {}}))

def exchange_rate(base: str, quote: str) -> str:
    """Return the exchange rate from one currency to another (live in real life)."""
    rates = {("USD", "EUR"): 0.92, ("USD", "GBP"): 0.79}
    return str(rates.get((base.upper(), quote.upper()), "unknown"))

# The schema the model sees. `name` must match the Python function.
TOOLS = [
    {
        "type": "function",
        "function": {
            "name": "calculator",
            "description": "Evaluate a basic arithmetic expression.",
            "parameters": {
                "type": "object",
                "properties": {"expression": {"type": "string"}},
                "required": ["expression"],
            },
        },
    },
    {
        "type": "function",
        "function": {
            "name": "exchange_rate",
            "description": "Get the exchange rate between two 3-letter currency codes.",
            "parameters": {
                "type": "object",
                "properties": {"base": {"type": "string"}, "quote": {"type": "string"}},
                "required": ["base", "quote"],
            },
        },
    },
]

DISPATCH = {"calculator": calculator, "exchange_rate": exchange_rate}
```

## Step 2: The Agent Loop

This is the whole idea. Call the model with the tools available. If it asks for a tool, run the function, append the result, and loop. If it doesn't, it's done.

```python
from openai import OpenAI

client = OpenAI()

def run_agent(question: str, max_steps: int = 5) -> tuple[str, int]:
    messages = [
        {"role": "system", "content": "You are a precise assistant. Use tools for math and live data instead of guessing."},
        {"role": "user", "content": question},
    ]
    for step in range(1, max_steps + 1):
        completion = client.chat.completions.create(
            model="gpt-4o",
            messages=messages,
            tools=TOOLS,
        )
        msg = completion.choices[0].message
        messages.append(msg)  # record what the model said/asked

        if not msg.tool_calls:
            return msg.content, step  # final answer — we're done

        # Otherwise, run each requested tool and feed the results back.
        for call in msg.tool_calls:
            args = json.loads(call.function.arguments)
            result = DISPATCH[call.function.name](**args)
            messages.append({
                "role": "tool",
                "tool_call_id": call.id,
                "content": str(result),
            })
    return "Stopped: hit max steps.", max_steps
```

## Step 3: Watch It Work

Give it a task that needs two tool calls in sequence — compute a number, then convert it:

```python
answer, steps = run_agent(
    "What is 15% of 240, and how much is that in euros?"
)
print(f"{answer}\n(solved in {steps} model turns)")
# 36 USD is about 33.12 EUR.
# (solved in 3 model turns)
```

The agent called `calculator("240 * 0.15")` → `36`, then `exchange_rate("USD","EUR")` → `0.92`, multiplied, and wrote the answer. You didn't orchestrate any of that — the *loop* did.

## Measuring the Difference

"Agents are powerful" is a claim. Here's how to make it a result: run the same questions with tools **off** vs **on** and check the answers.

```python
def ask_no_tools(question: str) -> str:
    completion = client.chat.completions.create(
        model="gpt-4o",
        messages=[{"role": "user", "content": question + " Answer with just the number."}],
    )
    return completion.choices[0].message.content

TESTS = [
    ("What is 4825 * 7919?", "38209175"),
    ("What is 15% of 240 in euros at the current rate?", "33.12"),
]

for q, expected in TESTS:
    plain = ask_no_tools(q)
    agent, _ = run_agent(q)
    print(f"Q: {q}\n  no-tools: {plain.strip()[:40]}\n  agent:    {agent.strip()[:40]}\n  expected: {expected}\n")
```

The no-tools model will often fumble the large multiplication and *cannot* know a live rate — it guesses. The agent gets both right because it can actually compute and look up. That gap (correct vs. plausible-but-wrong) is the entire value proposition, and now you can demonstrate it instead of asserting it.

## Common Pitfalls

| Mistake | Why it breaks | Fix |
|---|---|---|
| Forgetting to append the assistant message | The next call loses the pending tool call | `messages.append(msg)` before running tools |
| Not returning a `tool` message per call | The API errors on the next turn | Append one `{"role":"tool", "tool_call_id":...}` for **every** tool call |
| Tool `name` ≠ Python function | `KeyError` in dispatch | Keep the schema `name` and `DISPATCH` keys in sync |
| No `max_steps` guard | A confused agent loops forever | Cap the loop and fail loudly |
