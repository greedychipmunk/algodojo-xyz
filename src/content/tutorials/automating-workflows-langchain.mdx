## Why Automate with AI Agents?

Traditional automation tools (cron jobs, Zapier, Airflow) are great for **deterministic** workflows — processes where every step is predictable. But many business workflows involve:

- Unstructured data (emails, documents, chat messages)
- Decision-making that requires judgment
- Edge cases that break rigid rule-based systems

AI agents fill this gap by combining the **reliability of automation** with the **flexibility of human reasoning**.

## Architecture for Workflow Automation

A well-designed workflow automation system has four layers:

### 1. Trigger Layer

What kicks off the workflow? This could be:

- A new email arriving
- A file being uploaded
- A scheduled interval
- An API webhook

### 2. Processing Layer

The AI agent that orchestrates the workflow:

```python
from langchain_openai import ChatOpenAI
from langchain.agents import create_tool_calling_agent, AgentExecutor
from langchain_core.prompts import ChatPromptTemplate

llm = ChatOpenAI(model="gpt-4o", temperature=0)
```

### 3. Tool Layer

Functions the agent can call to interact with systems:

```python
from langchain.tools import tool
import json

@tool
def extract_invoice_data(text: str) -> str:
    """Extract structured data from invoice text.
    Returns JSON with vendor, amount, date, and line items."""
    # In production, this could use an LLM or specialized model
    prompt = f"Extract invoice data from: {text}"
    response = llm.invoke(prompt)
    return response.content

@tool
def save_to_database(data: str) -> str:
    """Save extracted data to the database.
    Expects JSON string with invoice fields."""
    parsed = json.loads(data)
    # Database insertion logic here
    return f"Saved invoice from {parsed.get('vendor', 'unknown')}"

@tool
def send_notification(message: str) -> str:
    """Send a Slack notification about processed invoices."""
    # Slack API call here
    return f"Notification sent: {message}"
```

### 4. Output Layer

Where results go — databases, notifications, dashboards, or downstream systems.

## Building an Invoice Processing Workflow

Let's build a complete workflow that automatically processes invoices from email attachments.

### The Agent Setup

```python
from langchain_core.prompts import ChatPromptTemplate

tools = [extract_invoice_data, save_to_database, send_notification]

prompt = ChatPromptTemplate.from_messages([
    ("system", """You are an invoice processing agent. When given invoice text:
1. Extract the structured data (vendor, amount, date, line items)
2. Save it to the database
3. Send a notification with a summary

Always validate extracted data before saving."""),
    ("human", "{input}"),
    ("placeholder", "{agent_scratchpad}"),
])

agent = create_tool_calling_agent(llm, tools, prompt)
executor = AgentExecutor(agent=agent, tools=tools, verbose=True)
```

### Processing an Invoice

```python
invoice_text = """
INVOICE #2025-0142
From: Acme Cloud Services

result = executor.invoke({"input": f"Process this invoice:\n{invoice_text}"})
```

## Error Handling and Reliability

Production workflows need robust error handling:

```python
from langchain.callbacks import StdOutCallbackHandler

class WorkflowErrorHandler(StdOutCallbackHandler):
    def on_tool_error(self, error: Exception, **kwargs) -> None:
        # Log error, send alert, and queue for manual review
        print(f"Tool error: {error}")
        send_notification(f"Workflow error: {error}")

executor = AgentExecutor(
    agent=agent,
    tools=tools,
    verbose=True,
    max_iterations=5,        # Prevent infinite loops
    handle_parsing_errors=True,  # Graceful error recovery
    callbacks=[WorkflowErrorHandler()],
)
```

## Patterns for Production Workflows

### Pattern 1: Human-in-the-Loop

For high-stakes decisions, add a human approval step:

```python
@tool
def request_human_approval(summary: str) -> str:
    """Request human approval for invoices over $10,000.
    Returns 'approved' or 'rejected'."""
    # In production: send to approval queue, wait for response
    return "approved"  # Placeholder
```

### Pattern 2: Batch Processing

Process multiple items efficiently:

```python
async def process_batch(invoices: list[str]) -> list[dict]:
    results = []
    for invoice in invoices:
        result = await executor.ainvoke({"input": f"Process: {invoice}"})
        results.append(result)
    return results
```

### Pattern 3: Retry with Backoff

```python
import asyncio

async def process_with_retry(input_text: str, max_retries: int = 3) -> dict:
    for attempt in range(max_retries):
        try:
            return await executor.ainvoke({"input": input_text})
        except Exception as e:
            if attempt == max_retries - 1:
                raise
            await asyncio.sleep(2 ** attempt)
    raise RuntimeError("Max retries exceeded")
```
