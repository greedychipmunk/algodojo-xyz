## What You'll Build

In the [from-scratch tutorial](/tutorials/intro-to-ai-agents) you hand-wrote the agent loop. Here you'll get the same behavior in a fraction of the code with **LangChain's `create_agent`** — the standard agent builder in LangChain 1.0 — and then do the part most intros skip: **measure that the agent calls the right tool.**

By the end you'll be able to spin up a tool-using agent and write a tiny eval that reports its tool-selection accuracy.

## Setup

LangChain 1.0 reorganized its namespace; `create_agent` replaces the older `AgentExecutor` / `create_tool_calling_agent` dance.

```bash

export OPENAI_API_KEY="sk-..."
```

## Step 1: Define Tools

A tool is a function with the `@tool` decorator. The type hints become its argument schema; the docstring tells the model when to use it.

```python
# agent.py
from langchain.tools import tool
from datetime import datetime

@tool
def calculator(expression: str) -> str:
    """Evaluate a basic arithmetic expression, e.g. '144 / 12'."""
    allowed = set("0123456789+-*/(). ")
    if not set(expression) <= allowed:
        return "Error: only numbers and + - * / ( ) allowed."
    return str(eval(expression, {"__builtins__": {}}))

@tool
def current_time() -> str:
    """Get the current date and time."""
    return datetime.now().strftime("%Y-%m-%d %H:%M:%S")

@tool
def word_count(text: str) -> int:
    """Count the number of words in a piece of text."""
    return len(text.split())
```

## Step 2: Create the Agent

`create_agent` wires the model, tools, and the reason→act→observe loop together. The model string uses the `provider:model` format.

```python
# agent.py
from langchain.agents import create_agent

agent = create_agent(
    model="openai:gpt-4o",
    tools=[calculator, current_time, word_count],
    system_prompt="You are a helpful assistant. Use a tool whenever one applies.",
)
```

## Step 3: Run It

Invoke with a list of messages; the final answer is the last message's content.

```python
# agent.py
result = agent.invoke(
    {"messages": [{"role": "user", "content": "What is 144 divided by 12?"}]}
)
print(result["messages"][-1].content)
# 144 divided by 12 is 12.
```

The agent inspected the request, decided `calculator` was the right tool, called it with `144 / 12`, and phrased the answer. That's the whole loop — handled for you.

## Step 4: Measure Tool Selection

An agent that answers correctly but for the wrong reason will betray you later. The thing to verify is **behavior**: did it call the tool you expected? Every message LangChain produces is in `result["messages"]`, and tool results arrive as messages with `type == "tool"` carrying the tool's `name` — so you can check exactly which tools fired.

```python
# agent.py
def tools_used(result) -> list[str]:
    return [m.name for m in result["messages"] if getattr(m, "type", None) == "tool"]

EVAL = [
    ("What is 18 * 37?",                         "calculator"),
    ("What's the date today?",                   "current_time"),
    ("How many words are in 'the quick brown fox'?", "word_count"),
    ("What is 1000 minus 256?",                  "calculator"),
]

correct = 0
for prompt, expected in EVAL:
    result = agent.invoke({"messages": [{"role": "user", "content": prompt}]})
    used = tools_used(result)
    hit = expected in used
    correct += hit
    print(f"{'✓' if hit else '✗'} expected={expected:13} used={used}  | {prompt}")

print(f"\nTool-selection accuracy: {correct}/{len(EVAL)} = {correct / len(EVAL):.0%}")
```

A typical run:

```text
✓ expected=calculator    used=['calculator']    | What is 18 * 37?
✓ expected=current_time  used=['current_time']  | What's the date today?
✓ expected=word_count    used=['word_count']    | How many words are in 'the quick brown fox'?
✓ expected=calculator    used=['calculator']    | What is 1000 minus 256?

Tool-selection accuracy: 4/4 = 100%
```

Now adding a tool or editing the system prompt has a feedback signal: rerun the eval and watch the number. When you later add overlapping tools (say, two search tools), this is how you catch the agent reaching for the wrong one.

## Common Pitfalls

| Mistake | Why it breaks | Fix |
|---|---|---|
| `from langchain.agents import AgentExecutor` | Legacy pre-1.0 API | Use `create_agent` from `langchain.agents` |
| Bare model name like `"gpt-4o"` | Provider can't be inferred | Use `"openai:gpt-4o"` and install `langchain-openai` |
| Reading the wrong message | `result` is a dict of messages | Final answer is `result["messages"][-1].content` |
| Thin/empty docstrings on tools | Model can't tell when to use them | Write a one-line description of *when* to call each tool |
